## What it does

`main.ts` writes a single one-line tombstone epitaph of famous last words — at most 150 characters, with the twist landing at the end — to `/output/entry.txt`. The program validates the competition gate before writing: 1–150 characters, one line, not only whitespace.

## Run

```sh
node main.ts
```
